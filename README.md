# Email System

A Java-based email management system built with Spring Boot and JavaFX. This project allows users to send, receive, and manage emails with a user-friendly interface.

## Features

- **User Authentication** - Secure login and sign-up system
- **Email Management** - Send, receive, and delete emails
- **User Settings** - Customizable preferences
- **JavaFX UI** - Interactive and user-friendly interface
- **Database Integration** - Hibernate & JPA for persistence
- **Logging** - Logback for structured logging

## Technologies Used

- **Java 17**
- **Spring Boot**
- **Spring Data JPA (Hibernate)**
- **JavaFX**
- **Maven**
- **PostgreSQL/MySQL** (configurable)
- **JUnit & Mockito** (for testing)
